Capacitor Foldable

Make your Capacitor app fold-aware on iPhone Duo, Galaxy Z Fold and Flip, and Pixel Fold. Fold state, posture, hinge angle, size classes and where the native bars go, from one plugin.

Built with it: Hinge Guess

Hinge Guess is a small game where the phone is the controller: fold it to the target angle, tap Measure, and score how close you got. Ionic Angular, Capacitor, and this plugin's hinge angle behind the dial, with the protractor's pivot sitting right on the crease.

Install

npm install @erkamyaman/capacitor-foldable
npx cap sync

Capacitor 8. On Capacitor 7, install @erkamyaman/capacitor-foldable@latest-7. Trying the Capacitor 9 beta? Install @erkamyaman/capacitor-foldable@next and follow the release notes. iPhone Duo support needs Capacitor 8.5+ and iOS 27.1, and works with any Xcode.

import { Foldable } from '@erkamyaman/capacitor-foldable';

const { posture } = await Foldable.getFoldState(); // 'flat' | 'tabletop' | 'book'

Foldable.addListener('foldStateChange', ({ posture }) => {
  document.documentElement.dataset.posture = posture;
});

What it tells your app

Fold state and posture

Flat, half-opened or closed, and whether the phone is held as a book or a tabletop.

Where the fold is

The hinge bounds and orientation, and whether the fold splits the web view in two.

Hinge angle

Live degrees from 0 to 180, plus a folding event while the hinge moves.

Inner or outer display

Which screen the app is on, and Material window size classes.

Bar placement

Which edge iPhone Duo moves native bars to, and how many points they take, so HTML tab bars can follow.

Android outer display

Rear display and dual screen on Android foldables.

Web standards, in a web view that turned them off

Chrome ships the Device Posture and Viewport Segments APIs, but Android's WebView disables both, and Safari 27.1 keeps them behind a flag an app can't set. installFoldablePolyfill() fills them in from the native fold state and mirrors the CSS features on <html>.

import { installFoldablePolyfill } from '@erkamyaman/capacitor-foldable';

await installFoldablePolyfill();

navigator.devicePosture.type; // 'continuous' | 'folded'
window.viewport.segments;     // two DOMRects when the fold splits the view

Ionic tabs on iPhone Duo

Native tab bars move to the side on iPhone Duo, but ion-tabs stays across the bottom, right over the fold. One import moves it the way the system does, and an opt-in fix stops the tab bar disappearing when the phone folds.

import '@erkamyaman/capacitor-foldable/ionic-tabs.css';

Want the controls rendered natively instead? See Capacitor Native UI below.

Agent prompt

Paste this into Claude Code, Cursor, Codex or any other coding agent working on your Capacitor app:

Task: Make this Capacitor app fold-aware on iPhone Duo and Android foldables
using @erkamyaman/capacitor-foldable.

Context:
- Docs: https://erkamyaman.github.io/capacitor-foldable/
- API: https://erkamyaman.github.io/capacitor-foldable/api.html
- If the capacitor-foldable skill is installed (node_modules/@erkamyaman/
  capacitor-foldable/skills/), read it first.
- Needs Capacitor 8.5 or later for iPhone Duo (iOS 27 scene lifecycle).
  On Capacitor 7, stop and report instead of upgrading on your own.

Steps:
1. npm install @erkamyaman/capacitor-foldable, then npx cap sync.
2. At startup, call installFoldablePolyfill() once. It fills in
   navigator.devicePosture and window.viewport.segments, and sets classes
   and variables on <html>: .device-posture-folded,
   .horizontal-viewport-segments-2, --fold-left, --fold-width,
   .vertical-bars-leading / .vertical-bars-trailing.
3. Keep interactive content out of the fold: when the view is split in two,
   lay out each half from --fold-left and --fold-width (or the viewport
   segments) instead of centering across the crease.
4. HTML tab bars and toolbars: iPhone Duo moves native bars to the side, but
   HTML bars stay put. Follow getBarPlacement() / barPlacementChange
   ({ verticalBarEdge: 'leading' | 'trailing' | null, inset }) or the
   .vertical-bars-* classes.
5. Ionic with ion-tabs: import '@erkamyaman/capacitor-foldable/ionic-tabs.css'.
   If the tab bar disappears after folding, pass { ionicKeyboard: true } to
   installFoldablePolyfill().
6. Use getHingeAngle() / hingeAngleChange only for features that really
   depend on the angle; layout should come from fold state and segments.

Deliverables:
1. Files changed, and which fold signals each screen uses.
2. Manual test poses: iPhone Duo closed, open portrait, open landscape, half
   folded (book and tabletop); an Android foldable folded and flat.

Constraints:
- Only use APIs from the plugin's definitions.ts and the docs above.
- Don't add fold logic to screens that look fine in every pose.
